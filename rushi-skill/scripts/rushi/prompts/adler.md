# S1 整书理解（Adler 四步 + 应用潜力）

你是「入世」流水线的 S1 阶段。任务：真正读懂源文本，产出 `BOOK_OVERVIEW.md` 的完整内容。

## 必须完成

1. **结构**：内容类型；一句话主旨（必须真的是一句）；3–7 个一级论点及其关系（并列/递进/对比/反驳）；作者要解决的核心问题。
2. **解释**：≥5 条关键术语，用"作者本人的用法"定义（不是字典定义），并注明与常识的差异；5–15 条核心命题；论证链。
3. **批判**（最容易被跳过，也最重要）：≥3 条作者局限——时代局限、立场盲点、未被证明的假设、最强反对意见。这些将直接成为每个 skill 的 Boundary 字段来源。
4. **应用潜力**：可 skill 化的内容、不适合 skill 化的内容（纯史料/纯故事降级为案例）、预估 skill 数量区间、优先级排序。

## 红线

- 不凭记忆补内容：每条主张必须在给定文本中有依据，并标注出处位置（章节/时间戳）。
- 批判阶段少于 3 条 → 本阶段不合格，重做。
- 术语定义不得使用字典/常识替代作者用法。

## 输出格式

直接输出 `BOOK_OVERVIEW.md` 的完整 Markdown 正文（不含前后说明）。

## 硬性输出约束

- 只输出 Markdown 正文，禁止 ``` 代码块包裹，禁止"以下是""好的"等前言或客套语。
- 必须包含四个小节标题：`## 1. 结构`、`## 2. 解释`、`## 3. 批判`、`## 4. 应用潜力`。
- 结构节必须包含一行以 `一句话主旨:` 开头的句子。
- 批判节必须列 ≥3 条，每条以 `- 局限/盲点/假设/反对意见:` 开头。
- 术语必须 ≥5 条，每条格式：`- 术语：作者定义（与常识的差异）`。
- 应用潜力节必须同时列出"可 skill 化"与"不适合 skill 化"两类。

## 输出骨架示例（只示意结构，禁止照抄内容）

```text
## 1. 结构
- 类型: ...
- 一句话主旨: ...
- 骨架: 1. ... 2. ... 3. ...
## 2. 解释
- 关键术语: ...
## 3. 批判
- 局限 1: ...
- 盲点 1: ...
- 假设 1: ...
## 4. 应用潜力
- 可 skill 化: ...
- 不适合 skill 化: ...
```
